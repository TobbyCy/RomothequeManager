**Principe transversal** : disponibilité actuelle du support, dernier inventaire, couverture et fraîcheur restent des dimensions différentes. OFFLINE, STALE et PARTIAL ne sont ni des preuves de suppression ni des compteurs à zéro. Les images du produit ne sont pas livrées par cette documentation ; cinq ressources graphiques attendent une vérification de droits.

La trajectoire d'un premier POC Windows portable à partir de fixtures synthétiques exige encore un mandat de développement et une Release privée de préversion vérifiée, sans données réelles.
