# Référence API ROMothèque Manager

Documentation technique générée depuis les commentaires XML C# de l'application. Les symboles exposés ici ne constituent **pas un SDK public stable**.

Cette référence ne donne aucune autorisation d'accès aux collections personnelles, ROMS, MEDIAS, aperçus ou stockage réel. Les chemins de preuve et fonctionnalités CI restent limités aux fixtures fictives.

Utiliser la navigation **API** pour consulter les types et leurs membres. Les informations de couverture et les manquants sont consignés dans les rapports du workflow GitHub Actions, et non dans ce site statique.
