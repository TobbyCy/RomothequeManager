# ROMothèque Manager

ROMothèque Manager est en préparation technique dans un dépôt **privé**.

Le code du moteur PowerShell historique est en cours d'export vers un historique Git indépendant. Les capacités existantes et celles étudiées pour les versions futures doivent rester explicitement distinguées.

**Sécurité :** essais exclusivement synthétiques. Aucun fichier ROM, BIOS, bibliothèque réelle ou état utilisateur ne doit être importé pour valider cette migration.

**État des publications :** aucune Release, licence de redistribution ou diffusion publique approuvée. Les ressources graphiques en attente de droits ne font pas partie de l'export.

La documentation de développement, de sécurité et de contribution sera consolidée séparément avant toute présentation publique.
