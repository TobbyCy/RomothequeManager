# Assistance et questions

ROMothèque Manager est **en cours de développement**. Aucun programme Windows final, package de production ni Release téléchargeable n'est actuellement fourni. Une spécification d'écran ne prouve pas qu'il existe dans l'application.

- **Question sur une fonctionnalité prévue** : consulter [Roadmap](docs/roadmap.md), [Statut](docs/product-status.md), [Parcours UX](docs/ux/README.md), puis ouvrir une Issue de question si nécessaire.
- **Bug sur du code de développement** : utiliser le formulaire Bug avec version/OS/commit, attendu/observé et fixture 100 % synthétique.
- **Proposition** : formulaire Feature et critères observables, sans promesse de date.
- **Sécurité** : suivre impérativement [SECURITY.md](SECURITY.md) sans divulguer de détails dans l'espace ouvert.

Ne joignez jamais de fichiers de jeu, dossiers ROM, BIOS, métadonnées privées, captures contenant des chemins ou identifiants matériels. Il n'y a **pas de service de support contractuel ni d'engagement de délai**. Aucun tutoriel ici n'autorise à modifier ou copier des collections réelles.
